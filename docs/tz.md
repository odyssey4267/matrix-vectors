# Техническое задание (ЛР №1, вариант 7)

## 1. Введение
Программа обрабатывает вещественную матрицу n × m и формирует логические векторы.

## 2. Основание для разработки
Лабораторная работа №1 по дисциплине «Инструментальные средства разработки ПО».

## 3. Назначение
Учебная программа для проверки условий по строкам и столбцам матрицы.

## 4. Требования к программе
- Ввод размеров n, m и элементов матрицы с клавиатуры.
- Вектор 1: все элементы k-го столбца нулевые.
- Вектор 2: элементы k-й строки упорядочены по убыванию.
- Вектор 3: k-я строка симметрична.
- Вывод исходной матрицы и трёх векторов на экран.
- Язык реализации: Python 3.

## 5. Требования к программной документации
README.md, техническое задание, описание архитектуры и плана тестирования.
