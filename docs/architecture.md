# Архитектура

Проект состоит из двух модулей в каталоге `src/`:

- `matrix_vectors.py` — чистые функции без ввода-вывода:
  `zero_columns`, `descending_rows`, `symmetric_rows`;
- `main.py` — консольный интерфейс: ввод матрицы и вывод результатов.

Логика отделена от интерфейса, поэтому функции можно тестировать
автоматически (`tests/test_matrix_vectors.py`).

Поток данных: ввод пользователя → матрица (список списков float) →
функции модуля → три списка bool → вывод на экран.
