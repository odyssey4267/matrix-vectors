# План тестирования

Инструмент: pytest. Запуск: `pytest -v`.

| № | Проверка | Входные данные | Ожидаемый результат |
|---|----------|----------------|---------------------|
| 1 | Нулевой столбец | первый столбец из нулей | `[True, False, False]` |
| 2 | Строки по убыванию | `[6,7,9]`, `[0,0,0]`, `[9,8,1]` | `[False, True, True]` |
| 3 | Симметричные строки | `[8,9,8]`, `[1,2,3]` | `[True, False]` |
| 4 | Нулевая матрица | все элементы 0 | все векторы из `True` |
