# Matrix Vectors

Учебный проект (вариант 7): по вещественной матрице n × m формируются
логические векторы.

## Назначение

Программа строит три логических вектора:

1. нулевые столбцы — `True`, если все элементы столбца равны нулю;
2. строки по убыванию — `True`, если элементы строки упорядочены по убыванию;
3. симметричные строки — `True`, если строка симметрична.

## Требования к окружению

- Python 3.8 или новее
- pytest и flake8 (для тестов и линтинга): `pip install -r requirements.txt`

## Запуск

```
python src/main.py
```

Тесты: `pytest`. Линтинг: `flake8 src tests`.

## Стратегия ветвления

Используется упрощённый Git Flow: `main` — стабильная версия,
`develop` — интеграционная ветка, новые функции делаются в `develop`
и сливаются в `main` после проверки. Выбор обоснован тем, что проект
учебный, разработчик один, а отдельная ветка `develop` позволяет
отработать слияние и разрешение конфликтов без риска для `main`.
